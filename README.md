# CPU 治具水中取出與氣槍吹乾模擬（wafer）

## 專題在做什麼

CPU 治具從水中取出後，表面會留下水珠，水也會沿著邊緣往下滴。本專題先在模擬中重現這段流程：

- **取件手臂**：伸入水缸，夾住治具左右兩側，提出水面後保持水平
- **氣槍手臂**：手臂末端裝上氣槍，從側面斜吹，掃過治具表面
- **水**：治具離水後留下水珠，部分水珠持續停留、部分滴落，氣流掃到的水珠會被吹走

## 模擬流程

| 時間 | 取件手臂 | 氣槍手臂 |
|---|---|---|
| 0–1.5 秒 | 回到起始姿勢 | 待命 |
| 1.5–7.5 秒 | 移到水缸上方，往下伸到治具 | 待命 |
| 7.5–8.5 秒 | 閉合手指夾住治具 | 待命 |
| 8.5–14.5 秒 | 提起治具到約 55 cm 高 | 待命，水珠開始滴落 |
| 14.5–16.5 秒 | 保持不動 | 待命，讓水自然滴落 |
| 16.5–20.5 秒 | 保持不動 | 帶氣槍移到治具側上方 |
| 20.5–25.5 秒 | 保持不動 | 掃過兩排並吹水 |
| 25.5–28.5 秒 | 保持不動 | 退回待命位置 |

氣槍斜吹 35 度，因為取件手臂的手掌就在治具正上方，無法垂直往下吹。

## 水的模型怎麼運作

水是自製的視覺粒子，沿用 `wetcloth-sim` 中 `drops.py`「水量累積到一滴才落下」的概念。

1. **留在表面**：治具離水後，上表面出現 320 顆水珠，下表面出現 120 顆，約 45% 的上表面水珠會一直停留。
2. **往邊緣移動**：其餘上表面水珠慢慢爬到邊緣，再繞到底面。
3. **累積成滴**：底面的水分到 8×8 的網格累積，滿約 0.05 mL 才落下一滴。
4. **水滴落下**：水滴做自由落體，落進水缸或碰到地面後消失。
5. **氣槍吹水**：氣流範圍內的水珠逐漸被移除，變成往外飛的水花。

手臂和物理每秒更新 240 次，粒子位置每 4 個物理步寫入一次 USD。

## 驗證結果

以下都是在 Isaac Sim 外試算的結果。

| 測試 | 結果 |
|---|---|
| 取件手臂路徑 | 指尖到達每個目標點，全程手掌朝下，未超過關節限位 |
| 氣槍手臂路徑 | 噴嘴到達每個掃描點，未超過關節限位 |
| 自然滴水 | 約 10 秒內落下 33 滴，之後剩 136 顆水珠留在治具上 |
| 氣槍吹水 | 2 秒自然滴水後吹水，水珠由 440 顆降到 66 顆 |

水珠位置是隨機產生的，每次的數字會略有不同。

## 快速開始

1. 開啟 Isaac Sim 6.0.1。
2. 到 **Window → Script Editor**，開啟並執行 `tank_pick_sim.py`。
3. 腳本會開新 stage、建立場景並自動開始，目前 stage 未存檔的內容會消失。
4. 到 Console 查看 `[tank]` 開頭的訊息。

| Console 訊息 | 說明 |
|---|---|
| `ready` | 場景與手臂初始化完成 |
| `joint tracking error` | 取件手臂到水缸上方時的關節誤差 |
| `drives are not following` | 手臂追不上目標，改為直接寫入關節位置 |
| `block grasped` | 治具已綁到取件手臂 |
| `water on the fixture` | 水珠開始出現，並印出各狀態的數量 |
| `blowing done` | 吹水結束，並印出剩餘水珠數 |

| 想調整的項目 | 參數 | 目前值 |
|---|---|---|
| 氣槍手臂底座位置 | `HELPER_BASE` | (1.15, 0) m |
| 治具尺寸 | `FIXTURE_SIZE` | 7 × 7 × 1.2 cm |
| 治具提起高度 | `LIFT_Z` | 0.55 m |
| 水珠數量 | `TOP_BEADS`、`UNDER_BEADS` | 320、120 |
| 留在治具上的比例 | `TRAPPED_FRACTION` | 0.45 |
| 氣槍傾斜角度 | `GUN_TILT_DEG` | 35° |
| 噴嘴到治具距離 | `GUN_STANDOFF` | 12 cm |
| 掃描排數與位置 | `GUN_RASTER_X` | +2 cm、−1 cm |

| 吹水範圍與速度 | `JET_RADIUS`、`JET_RATE` | 2.5 cm、12 /秒 |

## 已知問題

- **水不是流體模擬**：水缸是半透明方塊，水珠不會融合，也沒有表面張力。
- **氣流不是流體模擬**：吹水是移除範圍內的水珠，白色氣流只是視覺效果。
- **抓取是綁定的**：治具被夾住後直接跟著手走，重量不會傳到手臂關節。
- **治具尺寸受夾爪限制**：Franka 手指最多張開約 8 cm，實際治具若更寬，要改夾取方式或工具。
- **沒有完整碰撞檢查**：氣槍只有外觀、沒有碰撞。第二排吹水時，噴嘴離取件手掌約 3 cm，要實際確認。
- **未滿一滴的水會消失**：底面最後約 1.3 mL 的水不會滴下。
- **直接寫關節的備案**：若觸發，手臂會照路徑移動，但不受馬達力量限制。
